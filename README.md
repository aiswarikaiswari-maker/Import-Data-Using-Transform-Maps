Import Data Using Transform Maps

Project Overview

This project demonstrates how to import external data into ServiceNow using Import Sets and Transform Maps.

The project focuses on importing data, mapping source fields to target fields, transforming the data, and verifying the imported records.

Objectives

- Import external data into ServiceNow.
- Create and configure Import Sets.
- Create Transform Maps.
- Map source fields to target fields.
- Transform and validate imported records.

Technologies Used

- ServiceNow
- Import Sets
- Transform Maps
- Spreadsheet / CSV
- GitHub

Project Workflow

Source Data → Import Set → Transform Map → Field Mapping → Target Table → Verify Records

This project demonstrates a structured approach to importing and transforming external data in ServiceNow using Import Sets and Transform Maps.
